# MILIMAP

**현역 장병을 위한 군인 할인·우대 혜택 지도**

MILIMAP은 외출이나 휴가 때 방문할 지역의 군인 할인·우대 혜택을 찾아볼 수 있는 Android 앱입니다. 지도에서 업체를 찾고, 혜택 내용과 이용 조건을 확인한 뒤 관심 있는 곳을 찜할 수 있습니다.

## 주요 기능

- **지도 탐색** — 네이버 지도에서 좌표가 확인된 업체를 보고, 지도를 옮겨 현재 화면에 보이는 지역을 다시 검색할 수 있습니다.
- **지역과 업체 검색** — 방문할 지역, 업체명, 주소로 검색하고 음식·카페·숙박 등 카테고리로 결과를 좁힐 수 있습니다.
- **혜택 상세와 찜** — 할인·우대 내용, 이용 조건, 정보 출처를 확인하고 관심 있는 혜택을 저장할 수 있습니다.

## 혜택 데이터

병무청 나라사랑가게와 지방자치단체의 공개 자료를 바탕으로 혜택을 제공합니다. 좌표가 확인된 업체는 지도 핀으로 표시하고, 좌표가 미확정인 업체는 목록에서 주소를 확인할 수 있습니다.

[앱에 포함된 데이터 건수와 버전 보기](apps/android/app/src/main/assets/benefits.seed.manifest.json)

## Android에서 실행하기

1. 저장소를 복제하고 Android Studio에서 `apps/android` 폴더를 엽니다.
2. Gradle 동기화가 끝나면 Android 기기나 에뮬레이터를 선택합니다.
3. `app` 실행 구성을 선택하고 **Run**을 누릅니다.

[Android 설정 및 실행 안내](apps/android/README.md)
