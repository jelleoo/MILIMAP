# 혜택 데이터

`seed`에는 앱 초기 검증에 사용하는 수도권 혜택 데이터가 있습니다. Android 앱 실행용 JSON은 이 CSV에서 생성되어 `apps/android/app/src/main/assets`에 포함됩니다.

현재 Android 내장 데이터:

- 최신 공식 근거 출시 후보 249건
- 지도 핀 표시 9건: 정본 `확인 완료`이면서 엄격 POI 상호·주소 감사까지 통과한 업소
- 위치 확인 안내(지도 핀 미표시) 240건
- 업소별 공식 세부 할인 문구 74건, 공식 공통 혜택 문구 175건
- 최신 공식 근거가 부족한 247건과 사전 탑재 수동 seed 12건은 출시 시드에서 제외
- 음식, 카페, 미용·뷰티, 숙박 중심
- 병무청 나라사랑가게와 자체 조사·지자체 근거 통합

실시간 병무청 API 응답에는 좌표가 없습니다. 2026-09-04 API 기준 전체 2,367건 중 수도권은 806건이며, 주소 지오코딩 검증을 통과한 603건은 `mma.coordinates.seed.json`에 보존했습니다. 나머지 203건은 결과 없음·주소 불일치·복수 결과로 분리했으며 좌표를 추측하지 않았습니다. 다만 이 603건은 주소 일치 지오코딩 결과이므로 “지도 POI 상호·주소 모두 일치” 기준의 지도 핀 근거는 아닙니다. 현재 앱은 이 캐시를 지도 핀에 사용하지 않습니다.

정본 CSV의 좌표값과 감사 결과는 보존합니다. Android 출시 시드에는 정본 `확인 완료`와 엄격 POI 상호·주소 감사가 함께 충족된 좌표만 넣습니다. 그 외 출시 후보는 앱 목록과 상세의 위치 확인 안내로 표시하고 지도 핀에는 표시하지 않습니다. 데이터 수정 시 근거 URL, 데이터 기준일, 검증 상태를 유지합니다. 추정값을 사실처럼 입력하지 않습니다.

병무청 API로 새로 동기화한 업소는 최신 공식 목록 근거로 표시하되, 업소별 세부 할인 문구를 API가 제공하지 않으므로 “병무청 나라사랑가게 우대 혜택(업소별 적용 내용은 방문 전 확인)” 공통 문구와 좌표 없음 상태로 저장합니다. 같은 업소가 정본의 최신 지자체 공식 근거에 이미 있으면 정본의 세부·공통 공식 문구를 우선합니다.
