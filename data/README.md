# 혜택 데이터

`seed`에는 앱 초기 검증에 사용하는 수도권 혜택 데이터가 있습니다. Android 앱 실행용 JSON은 이 CSV에서 생성되어 `apps/android/app/src/main/assets`에 포함됩니다.

현재 데이터:

- 전체 484건
- 좌표 보유 484건
- 음식, 카페, 미용·뷰티, 숙박 중심
- 병무청 나라사랑가게와 자체 조사·지자체 근거 통합

실시간 병무청 API 응답에는 좌표가 없으므로 Android에는 별도의 검증 좌표 캐시를 포함합니다. 2026-09-04 API 기준 전체 2,367건 중 수도권은 806건이며, 엄격한 주소 검증을 통과한 603건만 `mma.coordinates.seed.json`에 저장했습니다. 나머지 203건은 결과 없음·주소 불일치·복수 결과로 분리했으며 좌표를 추측하지 않았습니다.

데이터 수정 시 근거 URL, 데이터 기준일, 검증 상태를 유지합니다. 추정값을 사실처럼 입력하지 않습니다.
